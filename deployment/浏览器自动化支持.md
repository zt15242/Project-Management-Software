# 🌐 浏览器自动化支持说明

## 问题说明

Windows 上的 `chromedriver.exe` 在 Linux 服务器上无法使用。本项目已配置完整的跨平台浏览器自动化支持。

---

## ✅ 已配置的解决方案

### 方案一：webdriver-manager（推荐）⭐

**优势**：
- ✅ 自动下载匹配版本的 ChromeDriver
- ✅ 跨平台支持（Windows/Linux/Mac）
- ✅ 自动管理驱动版本
- ✅ 无需手动配置

**Docker 配置**：
已在 `Dockerfile.backend` 中配置：
```dockerfile
# 安装 Google Chrome（Linux 版本）
RUN wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub | apt-key add - \
    && echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" >> /etc/apt/sources.list.d/google-chrome.list \
    && apt-get update \
    && apt-get install -y google-chrome-stable

# requirements.txt 中包含
selenium==4.15.2
webdriver-manager==4.0.1
```

**代码使用**：
```python
from webdriver_manager.chrome import ChromeDriverManager

# 自动下载并使用正确的驱动（跨平台）
service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service, options=chrome_options)
```

## 🔧 代码更新

### 已更新文件：`selenium_login.py`

**更新内容**：
1. ✅ 移除硬编码的 `chromedriver.exe`
2. ✅ 添加跨平台支持
3. ✅ 优先使用 webdriver-manager
4. ✅ 添加 Docker 环境所需参数

**关键改进**：
```python
# 旧代码（仅支持 Windows）
local_chromedriver = os.path.join(script_dir, "chromedriver.exe")

# 新代码（跨平台）
local_chromedriver_candidates = [
    os.path.join(script_dir, "chromedriver.exe"),  # Windows
    os.path.join(script_dir, "chromedriver"),      # Linux/Mac
    "/usr/local/bin/chromedriver",                 # Linux 常见位置
    "/usr/bin/chromedriver"                        # Linux 系统路径
]

# 自动选择可用的驱动
for candidate in local_chromedriver_candidates:
    if os.path.exists(candidate):
        local_chromedriver = candidate
        break

# 如果没有本地驱动，使用 webdriver-manager（推荐）
if not local_chromedriver:
    service = Service(ChromeDriverManager().install())
```

## 🐳 Docker 环境说明

### Chrome 选项配置

在 Docker 容器中运行时，需要特定的 Chrome 选项：

```python
chrome_options = Options()
chrome_options.add_argument('--headless')              # 无头模式（必需）
chrome_options.add_argument('--no-sandbox')            # Docker 必需
chrome_options.add_argument('--disable-dev-shm-usage') # Docker 必需
chrome_options.add_argument('--disable-gpu')           # 无 GPU 环境
chrome_options.add_argument('--disable-setuid-sandbox') # Docker 安全
chrome_options.add_argument('--remote-debugging-port=9222')
```

### 为什么需要这些参数？

| 参数 | 说明 | 必需性 |
|------|------|--------|
| `--headless` | 无头模式，不显示 UI | ✅ 服务器必需 |
| `--no-sandbox` | 禁用沙箱（Docker 需要） | ✅ Docker 必需 |
| `--disable-dev-shm-usage` | 使用 /tmp 而非 /dev/shm | ✅ Docker 必需 |
| `--disable-gpu` | 禁用 GPU 加速 | ✅ 无显卡环境 |
| `--disable-setuid-sandbox` | 禁用 setuid 沙箱 | ✅ Docker 权限 |

## 🧪 测试验证

### 测试 Selenium

```bash
# 在容器内测试
docker-compose exec backend python3 << EOF
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

options = Options()
options.add_argument('--headless')
options.add_argument('--no-sandbox')
options.add_argument('--disable-dev-shm-usage')

service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service, options=options)
driver.get('https://www.google.com')
print(f"✓ 页面标题: {driver.title}")
driver.quit()
EOF
```

        print(f"✓ 页面标题: {await page.title()}")

## 🔍 故障排查

### 问题 1: ChromeDriver 版本不匹配

**症状**：
```
selenium.common.exceptions.SessionNotCreatedException: 
Message: session not created: This version of ChromeDriver only supports Chrome version XX
```

**解决方案**：
```bash
# webdriver-manager 会自动解决此问题
# 如果仍有问题，手动更新：
docker-compose exec backend pip install --upgrade webdriver-manager selenium
docker-compose restart backend
```

### 问题 2: Chrome 未安装

**症状**：
```
selenium.common.exceptions.WebDriverException: 
Message: unknown error: cannot find Chrome binary
```

**解决方案**：
确保 Dockerfile.backend 中已安装 Chrome：
```dockerfile
RUN apt-get install -y google-chrome-stable
```

### 问题 3: 权限错误

**症状**：
```
selenium.common.exceptions.WebDriverException: 
Message: unknown error: Chrome failed to start: crashed
```

**解决方案**：
确保使用了正确的 Chrome 选项：
```python
chrome_options.add_argument('--no-sandbox')
chrome_options.add_argument('--disable-setuid-sandbox')
```

### 问题 4: 内存不足

**症状**：
浏览器启动缓慢或崩溃

**解决方案**：
```yaml
# 在 docker-compose.yml 中增加内存限制
services:
  backend:
    mem_limit: 2g
```

## 🎯 最佳实践

### 1. 优先使用 webdriver-manager

```python
# 自动管理，无需手动下载
from webdriver_manager.chrome import ChromeDriverManager
service = Service(ChromeDriverManager().install())
```

### 2. 配置合理的超时时间

```python
driver.set_page_load_timeout(30)  # 页面加载超时
driver.implicitly_wait(10)        # 元素查找超时
```

### 3. 确保正确关闭浏览器

```python
try:
    driver = webdriver.Chrome(...)
    # ... 操作
finally:
    if driver:
        driver.quit()  # 必须关闭，否则会内存泄漏
```

### 4. 使用无头模式

```python
# 服务器环境必须使用无头模式
chrome_options.add_argument('--headless')
```

### 5. 限制并发浏览器数量

```python
# 同时运行多个浏览器会占用大量资源
# 建议使用队列或信号量限制并发数
semaphore = asyncio.Semaphore(3)  # 最多3个并发
```
