## 🚀 部署流程（完整版）

### 第一步：准备服务器

```bash
# 1. 安装 Docker（Ubuntu 示例）
curl -fsSL https://get.docker.com | sh
sudo systemctl start docker
sudo systemctl enable docker

# 2. 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 3. 验证安装
docker --version
docker-compose --version
```

### 第二步：上传项目文件

```bash
# 方法1: 使用 SCP（从本地 Windows 上传）
scp -r "d:\销售易项目\项目管理软件2" user@your-server:/opt/project-management

# 方法2: 使用 Git
git clone <your-repo-url> /opt/project-management

# 方法3: 使用 FTP/SFTP 工具（如 FileZilla）
# 将整个项目上传到 /opt/project-management
```

### 第三步：配置环境

```bash
# 进入部署目录
cd /opt/project-management/deployment

# 复制配置模板
cp .env.production .env

# 编辑配置文件
nano .env

# 必须修改以下内容：
# 1. MONGO_INITDB_ROOT_PASSWORD=<修改为强密码>
# 2. SECRET_KEY=<使用下面命令生成>

# 生成随机密钥
openssl rand -hex 32
```

### 第四步：执行部署

```bash
# 赋予执行权限
chmod +x deploy.sh

# 构建 Docker 镜像（首次部署需要 15-30 分钟）
./deploy.sh build

# 启动所有服务
./deploy.sh start

# 查看服务状态
./deploy.sh status
```

### 第五步：验证部署

```bash
# 1. 检查所有容器是否运行
docker ps

# 预期输出：
# pm_frontend   - 前端服务
# pm_backend    - 后端服务
# pm_mongodb    - 数据库服务

# 2. 测试后端健康状态
curl http://localhost:8000/api/health

# 3. 测试前端访问
curl http://localhost

# 4. 在浏览器访问
# 前端: http://your-server-ip
# API文档: http://your-server-ip:8000/docs
```

## 📊 系统架构说明

### 服务组成

```
┌─────────────────────────────────────────────────┐
│  用户浏览器                                      │
└────────────┬────────────────────────────────────┘
             │ HTTP (Port 80)
             ▼
┌─────────────────────────────────────────────────┐
│  Nginx 容器 (pm_frontend)                        │
│  - 提供 Vue.js 静态文件                          │
│  - 反向代理 API 请求到后端                       │
│  - Gzip 压缩                                     │
│  - 资源缓存                                      │
└────────────┬────────────────────────────────────┘
             │ HTTP Proxy (Port 8000)
             ▼
┌─────────────────────────────────────────────────┐
│  FastAPI 容器 (pm_backend)                       │
│  - Python 3.11                                   │
│  - RESTful API                                   │
│  - JWT 认证                                      │
│  - 支持 Selenium + Playwright                    │
└────────────┬────────────────────────────────────┘
             │ MongoDB Protocol (Port 27017)
             ▼
┌─────────────────────────────────────────────────┐
│  MongoDB 容器 (pm_mongodb)                       │
│  - MongoDB 6.0                                   │
│  - 用户认证                                      │
│  - 数据持久化                                    │
└─────────────────────────────────────────────────┘

Docker Volumes (数据持久化):
├─ mongodb_data       → 数据库文件
├─ mongodb_config     → 数据库配置
├─ backend_uploads    → 用户上传文件
└─ backend_logs       → 应用日志
```

### 网络配置

- **内部网络**: pm_network (Docker bridge 网络)
- **外部端口**:
  - 80 → Nginx (前端)
  - 8000 → FastAPI (后端)
  - 27017 → MongoDB (可选外部访问)

### 健康检查

每个服务都配置了健康检查：
- **MongoDB**: 每 10 秒检查一次
- **Backend**: 每 30 秒检查 `/api/health` 端点
- **Frontend**: 每 30 秒检查 Nginx 响应

## 🔧 常用管理命令速查

### 服务管理

```bash
cd /opt/project-management/deployment

# 启动服务
./deploy.sh start

# 停止服务
./deploy.sh stop

# 重启服务
./deploy.sh restart

# 查看状态
./deploy.sh status

# 查看帮助
./deploy.sh help
```

### 日志查看

```bash
# 查看所有服务日志（实时）
./deploy.sh logs

# 查看特定服务日志
./deploy.sh logs backend
./deploy.sh logs frontend
./deploy.sh logs mongodb

# 或使用 Docker Compose
docker-compose logs -f --tail=100 backend
```

### 数据管理

```bash
# 备份数据库
./deploy.sh backup
# 备份文件保存在: ../backups/mongodb_backup_YYYYMMDD_HHMMSS.archive

# 恢复数据库
./deploy.sh restore ../backups/mongodb_backup_20251222_120000.archive

# 查看数据卷
docker volume ls
docker volume inspect deployment_mongodb_data
```

### 资源监控

```bash
# 查看容器资源使用（CPU、内存）
docker stats

# 查看磁盘使用
docker system df

# 查看特定容器详情
docker inspect pm_backend
```

## 🔒 安全配置重点

### ⚠️ 部署前必须修改

**1. MongoDB 密码**
```env
MONGO_INITDB_ROOT_PASSWORD=change_this_password_in_production
```
修改为：至少 16 位的强密码

**2. JWT 密钥**
```env
SECRET_KEY=change_this_to_a_random_secret_key_at_least_32_characters_long
```
使用命令生成：
```bash
openssl rand -hex 32
```

### 🛡️ 生产环境建议

```bash
# 1. 配置防火墙
sudo ufw enable
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS (如果启用)
sudo ufw deny 27017/tcp    # 禁止外部访问 MongoDB

# 2. 启用 HTTPS（推荐使用 Let's Encrypt）
sudo apt-get install certbot
sudo certbot certonly --standalone -d your-domain.com

# 3. 定期备份（设置 cron 任务）
crontab -e
# 添加: 0 2 * * * cd /opt/project-management/deployment && ./deploy.sh backup

# 4. 监控磁盘空间
# 添加: 0 3 * * * find /opt/project-management/backups -mtime +30 -delete
```

## 📈 性能优化建议

### 1. 服务器配置

**最低配置**:
- 2核 CPU + 4GB 内存 + 20GB 磁盘

**推荐配置**:
- 4核 CPU + 8GB 内存 + 50GB SSD

**高负载配置**:
- 8核 CPU + 16GB 内存 + 100GB SSD

### 2. Docker 资源限制

编辑 `docker-compose.yml` 添加：

```yaml
services:
  backend:
    deploy:
      resources:
        limits:
          cpus: '2.0'
          memory: 2G
        reservations:
          cpus: '1.0'
          memory: 1G
```

### 3. MongoDB 索引优化

```bash
# 进入 MongoDB 容器
docker-compose exec mongodb mongosh \
  --username admin \
  --password <your_password>

# 切换数据库
use project_management

# 创建索引
db.users.createIndex({email: 1})
db.projects.createIndex({created_by: 1})
db.tasks.createIndex({project_id: 1, assignee: 1})
db.bugs.createIndex({project_id: 1, status: 1})
```

## 🐛 故障排查指南

### 问题 1: 容器无法启动

```bash
# 查看容器状态
docker ps -a

# 查看失败容器日志
docker logs <container_id>

# 检查端口占用
netstat -tlnp | grep 80
netstat -tlnp | grep 8000
netstat -tlnp | grep 27017
```

### 问题 2: MongoDB 连接失败

```bash
# 检查 MongoDB 容器
docker ps | grep mongodb

# 查看 MongoDB 日志
./deploy.sh logs mongodb

# 测试连接
docker-compose exec mongodb mongosh \
  --username admin \
  --password <your_password> \
  --eval "db.runCommand({ping:1})"
```

### 问题 3: 前端无法访问

```bash
# 检查 Nginx 容器
docker ps | grep frontend

# 查看 Nginx 日志
./deploy.sh logs frontend

# 测试 Nginx 配置
docker-compose exec frontend nginx -t

# 检查防火墙
sudo ufw status
```

### 问题 4: 后端 API 报错

```bash
# 查看后端日志
./deploy.sh logs backend

# 进入容器调试
docker-compose exec backend bash
python --version
pip list
```

### 问题 5: 磁盘空间不足

```bash
# 检查磁盘使用
df -h

# 清理 Docker 资源
docker system prune -a --volumes

# 清理旧日志
find /opt/project-management/backend/logs -name "*.log" -mtime +7 -delete
```
