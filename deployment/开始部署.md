# 🐳 Linux 服务器 Docker 部署

本项目已配置完整的 Docker 部署方案，支持一键部署到 Linux 服务器。

## 📁 部署文件位置

所有部署相关的文件都在 **`deployment/`** 目录下。

## 🚀 快速开始

### 查看部署文档

```bash
cd deployment
```

**推荐阅读顺序**：

1. **部署总结.md** - 📖 中文版完整部署指南（推荐！）
2. **CHECKLIST.md** - ✅ 部署前检查清单
3. **README.md** - 📚 英文版详细文档
4. **FAQ.md** - ❓ 常见问题解答

### 最简部署（3步）

```bash
# 1. 进入部署目录
cd deployment

# 2. 配置环境变量
cp .env.production .env
nano .env  # 修改密码和密钥

# 3. 执行部署
chmod +x deploy.sh
./deploy.sh build
./deploy.sh start
```

## 📋 系统要求

- **操作系统**: Linux (Ubuntu 20.04+, CentOS 7+, Debian 10+)
- **CPU**: 2核或以上
- **内存**: 4GB 或以上（推荐 8GB）
- **磁盘**: 20GB 可用空间
- **软件**: Docker 20.10+ 和 Docker Compose 1.29+

## 📦 部署包内容

### 核心配置（5个文件）
- `docker-compose.yml` - 服务编排配置
- `Dockerfile.backend` - 后端镜像
- `Dockerfile.frontend` - 前端镜像
- `.env.production` - 环境配置模板
- `.dockerignore` - 构建优化

### 部署脚本（2个文件）
- `deploy.sh` - 主部署脚本
- `quick-deploy.sh` - 快速部署脚本

### 文档文件（5个文件）
- `部署总结.md` - 中文完整指南 ⭐⭐⭐⭐⭐
- `README.md` - 英文详细文档
- `INDEX.md` - 文件索引
- `CHECKLIST.md` - 检查清单
- `FAQ.md` - 常见问题

## 🔧 常用命令

```bash
cd deployment

# 服务管理
./deploy.sh start      # 启动服务
./deploy.sh stop       # 停止服务
./deploy.sh restart    # 重启服务
./deploy.sh status     # 查看状态

# 日志查看
./deploy.sh logs       # 查看所有日志
./deploy.sh logs backend   # 查看后端日志

# 数据管理
./deploy.sh backup     # 备份数据库
./deploy.sh restore <file>  # 恢复数据库
```

部署完成后：

## ⚠️ 重要提示

部署前必须修改 `.env` 文件中的：

1. `MONGO_INITDB_ROOT_PASSWORD` - MongoDB 密码
2. `SECRET_KEY` - JWT 密钥（使用 `openssl rand -hex 32` 生成）
