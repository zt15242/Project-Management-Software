## 🔧 技术细节

### 1. Initial Prompt
```python
initial_prompt = "以下是普通话的句子。"
```

**作用**:
- 提示Whisper使用简体中文
- 提高中文识别准确度
- 减少英文混入

### 2. Beam Size
```python
beam_size=5  # 从1增加到5
```

**作用**:
- 增加搜索路径,提高准确度
- 但会增加计算时间
- 5是准确度和速度的平衡点

### 3. OpenCC繁简转换
```python
from opencc import OpenCC
cc = OpenCC('t2s')  # 繁体转简体
text = cc.convert(text)
```

**作用**:
- 自动将繁体中文转为简体
- 确保输出统一为简体中文
- 即使Whisper输出繁体也会转换

## ⚙️ 模型选择建议

### 如需更高准确度

可以升级到medium或large模型:

```python
# medium模型: 准确度~90%, 速度2-3x实时
_whisper_model = WhisperModel("medium", device="cpu", compute_type="int8")

# large模型: 准确度~95%, 速度1-2x实时
_whisper_model = WhisperModel("large-v3", device="cpu", compute_type="int8")
```

**注意**: 更大的模型需要更多时间和内存

### 如需更快速度

可以降级到base或tiny模型:

```python
# base模型: 准确度~80%, 速度10-15x实时
_whisper_model = WhisperModel("base", device="cpu", compute_type="int8")

# tiny模型: 准确度~70%, 速度20-30x实时
_whisper_model = WhisperModel("tiny", device="cpu", compute_type="int8")
```

## 🎯 优化参数说明

### beam_size (搜索宽度)
- **1**: 最快,准确度最低
- **5**: 平衡点 ⭐ 推荐
- **10**: 更准确,但很慢

### language (语言)
- **"zh"**: 中文 ⭐ 推荐
- **None**: 自动检测(可能识别为英文)

### vad_filter (语音活动检测)
- **True**: 过滤静音 ⭐ 推荐
- **False**: 不过滤

### initial_prompt (初始提示)
- **"以下是普通话的句子。"**: 简体中文 ⭐ 推荐
- **"以下是繁體中文的句子。"**: 繁体中文
- **None**: 无提示

### task (任务类型)
- **"transcribe"**: 转录 ⭐ 推荐
- **"translate"**: 翻译成英文

## 🔍 故障排除

### 问题1: 模型下载失败
**错误**: "Faster-Whisper模型下载失败"

**解决**:
1. 检查网络连接
2. 使用国内镜像: 取消注释 `os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"`
3. 手动下载模型

### 问题2: 内存不足
**错误**: "MemoryError"

**解决**:
1. 降级到base模型
2. 增加服务器内存
3. 使用GPU加速

### 问题3: 转录速度太慢
**错误**: 处理时间超过预期

**解决**:
1. 降级到base模型
2. 减小beam_size到1
3. 使用GPU加速

### 问题4: 仍然有繁体字
**错误**: 转录结果包含繁体字

**解决**:
1. 确认OpenCC已安装
2. 检查日志是否有OpenCC错误
3. 手动测试OpenCC: `python -c "from opencc import OpenCC; print(OpenCC('t2s').convert('繁體'))"`
