# 会议转录系统 - 最终简化版

## 🎯 核心功能

**一键上传,自动生成会议纪要**

- 上传音频/视频文件
- 系统自动转录
- AI自动生成纪要
- 无需任何手动操作

## ✅ 已移除的功能

1. ❌ 说话人识别 - 不再显示说话人数量
2. ❌ 说话人确认 - 不需要手动确认
3. ❌ 音频切割 - 不生成wav片段文件
4. ❌ 手动操作 - 全程自动化

## 📋 工作流程

```
上传文件 → 自动转录 → AI生成纪要 → 完成
```

**就这么简单!**

## 🎁 输出内容

### 1. 完整转录文本
- 按时间轴分段
- 每个片段包含:
  - 开始时间
  - 结束时间  
  - 转录文字

### 2. AI会议纪要 (Markdown格式)
- 会议概览
- 详细内容摘要
- 关键结论与决策
- 待办事项/行动项
- 总结

## ⏱️ 处理时间

| 音频时长 | 处理时间 |
|---------|---------|
| 5分钟 | ~30-40秒 |
| 10分钟 | ~1-1.5分钟 |
| 30分钟 | ~3-4分钟 |
| 60分钟 | ~6-8分钟 |
| 75分钟 | ~8-10分钟 |

## 🚀 使用步骤

### 1. 重启服务

**后端**:
```bash
# 停止当前后端 (Ctrl+C)
python .\main.py
```

**前端**:
```bash
# 刷新浏览器页面即可
```

### 2. 上传新文件

- 点击"上传会议录音/视频"
- 选择文件
- 填写标题和描述
- 点击上传

### 3. 等待完成

- 状态会显示"处理中"
- 处理完成后自动变为"已完成"
- 点击"查看摘要"即可查看AI纪要

## 📊 界面变化

### 会议列表

**移除了**:
- ❌ "说话人"列
- ❌ "确认说话人"按钮

**保留了**:
- ✅ 会议标题
- ✅ 状态
- ✅ 文件大小
- ✅ 创建时间
- ✅ 操作按钮(查看摘要、详情、重试、删除)

### 状态说明

| 状态 | 说明 |
|------|------|
| 上传中 | 文件正在上传 |
| 处理中 | 正在提取音频 |
| 转录中 | Whisper正在转录 |
| 生成中 | AI正在生成纪要 |
| 已完成 | 全部完成,可查看纪要 |
| 失败 | 处理失败,可重试 |

## ⚙️ 技术参数

- **模型**: Faster-Whisper base
- **准确度**: ~80%
- **速度**: 10-15x实时
- **语言**: 中文
- **输出**: 转录文本 + AI纪要

## 📝 注意事项

### 1. 旧会议记录

之前上传的会议记录仍然会显示"说话人"信息,这是正常的。

**新上传的文件**将使用新的全自动流程。

### 2. AI配置

必须在系统设置中配置AI才能自动生成纪要。

如未配置,会停留在"等待确认"状态。

### 3. 文件格式

支持的格式:
- **音频**: mp3, wav, m4a, aac, flac, ogg
- **视频**: mp4, avi, mov, mkv, flv, wmv

### 4. 文件大小

建议单个文件不超过2小时(约500MB)
