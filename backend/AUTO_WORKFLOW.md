# 会议转录全自动流程说明

## 🎯 最终优化方案

### 核心改进
1. ✅ **使用base模型** - 准确度提升到80%
2. ✅ **跳过音频切割** - 不生成wav片段文件
3. ✅ **全自动流程** - 转录后直接生成AI纪要,无需手动确认
4. ✅ **性能优化** - 使用Faster-Whisper,速度提升5-7倍

## 📋 完整流程

### 用户操作
```
1. 上传会议文件 (音频/视频)
2. 等待处理完成
3. 查看AI生成的会议纪要
```

**就这么简单!** 全程自动,无需任何手动操作。

### 系统处理流程

```
上传文件
   ↓
提取音频 (如果是视频) [~10秒]
   ↓
Whisper转录 [~6-8分钟/75分钟音频]
   ↓
处理片段 [~0.2秒]
   ↓
自动生成AI纪要 [~20-30秒]
   ↓
完成! 状态变为"已完成"
```

## 🚀 使用步骤

### 1. 确保AI已配置

在系统设置中配置AI:
- API Key
- Base URL (可选)
- Model (可选,默认gpt-3.5-turbo)

### 2. 重启后端服务

由于更新了模型,需要重启:

```bash
# 停止当前后端 (Ctrl+C)
# 重新启动
python .\main.py
```

首次启动会下载base模型(约142MB)

### 3. 上传会议文件

支持的格式:
- **音频**: mp3, wav, m4a, aac, flac, ogg
- **视频**: mp4, avi, mov, mkv, flv, wmv

### 4. 等待处理

- 系统会显示"处理中"状态
- 可以在日志中查看进度
- 处理完成后状态变为"已完成"

### 5. 查看结果

- 点击会议查看详情
- 可以看到完整的转录文本
- 可以下载AI生成的会议纪要

## ⚙️ 配置选项

### 如需更高准确度

在 `meetings.py` 第154行修改模型:

```python
# 当前: base模型 (准确度~80%, 速度10-15x实时)
_whisper_model = WhisperModel("base", device="cpu", compute_type="int8")

# 选项1: small模型 (准确度~85%, 速度5-8x实时)
_whisper_model = WhisperModel("small", device="cpu", compute_type="int8")

# 选项2: medium模型 (准确度~90%, 速度2-3x实时)
_whisper_model = WhisperModel("medium", device="cpu", compute_type="int8")
```

**注意**: 更大的模型会显著增加处理时间

### 如有GPU

可以启用GPU加速:

```python
_whisper_model = WhisperModel("base", device="cuda", compute_type="float16")
# 速度可以再提升3-5倍!
```

## ⚠️ 注意事项

### 1. AI配置必需
- 必须在系统中配置AI才能自动生成纪要
- 如未配置,会停留在"等待确认"状态

### 2. 文件大小限制
- 建议单个文件不超过2小时
- 超长文件会显著增加处理时间

### 3. 音频质量
- 清晰的录音效果更好
- 减少背景噪音
- 避免回声和混响

### 4. 网络要求
- 首次使用需要下载模型
- AI纪要生成需要网络连接
