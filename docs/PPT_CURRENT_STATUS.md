### 方案 B：启用 AI 图片生成

如果您需要图片与内容完美匹配，可以：

**选项 1：使用 OpenAI 官方**

在 `backend/.env` 中添加：
```bash
GEMINI_IMAGE_API_KEY=sk-your-openai-key
GEMINI_IMAGE_BASE_URL=https://api.openai.com/v1
```

成本：约 $0.04-0.12/张图片

**选项 2：使用其他支持图片生成的中转服务**

找一个支持以下接口的服务：
- `/v1/images/generations`
- 兼容 DALL-E 3 格式
