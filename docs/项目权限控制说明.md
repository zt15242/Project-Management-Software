## 权限控制规则

### 1. 项目创建权限

**规则**: 只有**系统管理员**和**项目经理**可以创建项目

**实现位置**: `backend/routers/projects.py` - `create_project()`

**权限检查**:
```python
if current_user.role not in [UserRole.ADMIN, UserRole.PROJECT_MANAGER]:
    raise HTTPException(
        status_code=403, 
        detail="没有权限创建项目，只有系统管理员和项目经理可以创建项目"
    )
```

**角色说明**:
- ✅ **系统管理员** (`ADMIN`) - 可以创建项目
- ✅ **项目经理** (`PROJECT_MANAGER`) - 可以创建项目
- ❌ **开发者** (`DEVELOPER`) - 不能创建项目
- ❌ **测试人员** (`TESTER`) - 不能创建项目

---

### 2. 项目查看权限

**规则**: 
- **系统管理员**和**项目经理**可以查看所有项目
- **开发者**和**测试人员**只能查看自己参与的项目（即自己在 `team_members` 列表中的项目）

**实现位置**: `backend/routers/projects.py` - `get_projects()`

**权限检查**:
```python
if current_user.role in [UserRole.ADMIN, UserRole.PROJECT_MANAGER]:
    # 管理员和项目经理查看所有项目
    projects = await db.projects.find().to_list(length=None)
else:
    # 其他角色只能看到自己是团队成员的项目
    projects = await db.projects.find({"team_members": current_user.id}).to_list(length=None)
```

**角色说明**:
- ✅ **系统管理员** (`ADMIN`) - 查看所有项目
- ✅ **项目经理** (`PROJECT_MANAGER`) - 查看所有项目
- 🔒 **开发者** (`DEVELOPER`) - 只能查看参与的项目
- 🔒 **测试人员** (`TESTER`) - 只能查看参与的项目

---

### 3. 项目成员管理权限

#### 3.1 添加成员

**规则**: 以下角色可以添加成员：
- 系统管理员
- 项目经理（角色）
- 项目所有者（创建该项目的人）
- 项目负责人（被指定为该项目的项目经理）

**实现位置**: `backend/routers/projects.py` - `add_team_member()`

**权限检查**:
```python
is_owner = current_user.id == project["owner_id"]
is_pm = current_user.id == project.get("project_manager_id")
if current_user.role not in [UserRole.ADMIN, UserRole.PROJECT_MANAGER] and not is_owner and not is_pm:
    raise HTTPException(
        status_code=403, 
        detail="没有权限，只有系统管理员、项目经理、项目所有者或项目负责人可以管理成员"
    )
```

#### 3.2 移除成员

**规则**: 与添加成员相同，但有额外限制：
- 不能移除项目所有者
- 不能移除项目负责人（需先更换项目负责人）

**实现位置**: `backend/routers/projects.py` - `remove_team_member()`

---

### 4. 项目信息修改权限

**规则**: 以下角色可以修改项目信息：
- 系统管理员
- 项目所有者
- 项目负责人

**实现位置**: `backend/routers/projects.py` - `update_project()`

**权限检查**:
```python
is_owner = current_user.id == project["owner_id"]
is_pm = current_user.id == project.get("project_manager_id")
if current_user.role != UserRole.ADMIN and not is_owner and not is_pm:
    raise HTTPException(
        status_code=403, 
        detail="没有权限，只有管理员、项目所有者或项目经理可以修改项目"
    )
```

## 前端权限控制建议

### 1. 创建项目按钮显示控制

在前端，建议根据用户角色控制"创建项目"按钮的显示：

```vue
<el-button 
  v-if="userStore.isAdmin || userStore.role === 'project_manager'" 
  type="primary" 
  @click="showCreateDialog"
>
  创建项目
</el-button>
```

### 2. 项目列表提示

对于非管理员用户，可以在项目列表页面添加提示：

```vue
<el-alert 
  v-if="!userStore.isAdmin" 
  type="info" 
  :closable="false"
  style="margin-bottom: 20px;"
>
  您当前只能查看自己参与的项目。如需查看所有项目，请联系系统管理员。
</el-alert>
```

### 3. 成员管理按钮控制

在项目详情页，控制成员管理按钮的显示：

```vue
<el-button 
  v-if="canManageMembers" 
  type="primary" 
  @click="showAddMemberDialog"
>
  添加成员
</el-button>

<script setup>
const canManageMembers = computed(() => {
  return userStore.isAdmin || 
         userStore.role === 'project_manager' ||
         currentProject.value.owner_id === userStore.userId ||
         currentProject.value.project_manager_id === userStore.userId
})
</script>
```

## 注意事项

1. **项目所有者自动加入团队**: 创建项目时，创建者会自动成为团队成员
2. **项目经理自动加入团队**: 指定项目经理时，该用户会自动加入团队成员
3. **不能移除关键角色**: 不能移除项目所有者和项目负责人
4. **权限继承**: 系统管理员拥有所有权限
5. **角色vs职位**: 区分系统角色（如PROJECT_MANAGER）和项目职位（如project_manager_id）
