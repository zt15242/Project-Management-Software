# 后台任务管理功能 - 完整集成指南

## 功能概述

在侧边栏添加全新的"后台任务管理"板块，用于监控和管理系统中的后台进程任务（如会议分析、数据导出等）。

## 功能特性

### 1. 任务监控
- ✅ 实时显示任务状态（运行中/已暂停/已完成/失败）
- ✅ 显示任务进度（0-100%）
- ✅ 实时监控系统资源占用（CPU、内存）
- ✅ 显示任务耗时（创建时间、持续时间）

### 2. 任务操作
- ✅ **暂停任务** - 暂停正在运行的任务
- ✅ **继续任务** - 恢复已暂停的任务
- ✅ **停止任务** - 强制停止任务
- ✅ **删除任务** - 删除已完成/失败的任务记录

### 3. 数据统计
- ✅ 总任务数
- ✅ 运行中任务数
- ✅ 已暂停任务数
- ✅ 已完成任务数
- ✅ 失败任务数

### 4. 筛选功能
- ✅ 按任务类型筛选（会议分析、数据导出等）
- ✅ 按状态筛选
- ✅ 自动刷新（每5秒）

### 步骤3：修改会议分析流程（集成任务记录）

在 `backend/routers/meetings.py` 的 `process_meeting_file` 函数中，添加任务记录：

```python
async def process_meeting_file(meeting_id: str):
    """后台任务：处理会议文件"""
    db = get_database()
    meeting = await db.meetings.find_one({"_id": ObjectId(meeting_id)})
    
    # 创建后台任务记录
    task_doc = {
        "task_type": "meeting_analysis",
        "task_name": f"会议分析: {meeting['title']}",
        "status": "running",
        "created_at": get_beijing_time(),
        "started_at": get_beijing_time(),
        "created_by": meeting["created_by"],
        "related_id": meeting_id,
        "progress": 0,
        "cpu_percent": 0.0,
        "memory_mb": 0.0
    }
    task_result = await db.background_tasks.insert_one(task_doc)
    task_id = str(task_result.inserted_id)
    
    try:
        # 1. 音频提取
        await update_task_progress(task_id, 10, "音频提取中...")
        # ... 音频提取代码 ...
        
        # 2. Whisper转录
        await update_task_progress(task_id, 30, "AI转录中...")
        # ... 转录代码 ...
        
        # 3. NLP处理
        await update_task_progress(task_id, 70, "文本处理中...")
        # ... NLP处理代码 ...
        
        # 4. 完成
        await update_task_progress(task_id, 100, "完成")
        await db.background_tasks.update_one(
            {"_id": ObjectId(task_id)},
            {
                "$set": {
                    "status": "completed",
                    "completed_at": get_beijing_time(),
                    "progress": 100
                }
            }
        )
        
    except Exception as e:
        # 任务失败
        await db.background_tasks.update_one(
            {"_id": ObjectId(task_id)},
            {
                "$set": {
                    "status": "failed",
                    "completed_at": get_beijing_time(),
                    "error_message": str(e)
                }
            }
        )
        raise


async def update_task_progress(task_id: str, progress: int, message: str = None):
    """更新任务进度"""
    db = get_database()
    
    # 获取当前进程的资源占用
    import psutil
    process = psutil.Process()
    cpu_percent = process.cpu_percent(interval=0.1)
    memory_mb = process.memory_info().rss / 1024 / 1024
    
    update_data = {
        "progress": progress,
        "cpu_percent": cpu_percent,
        "memory_mb": memory_mb,
        "updated_at": get_beijing_time()
    }
    
    if message:
        update_data["current_step"] = message
    
    await db.background_tasks.update_one(
        {"_id": ObjectId(task_id)},
        {"$set": update_data}
    )
```

## 使用流程

1. **用户上传会议视频**
   - 系统创建后台任务记录
   - 任务状态：running
   - 进度：0%

2. **任务执行过程**
   - 音频提取：进度 10%
   - AI转录：进度 30-70%
   - 文本处理：进度 70-90%
   - 生成纪要：进度 90-100%
   - 实时更新CPU和内存占用

3. **用户操作**
   - 查看任务列表
   - 暂停正在运行的任务
   - 继续已暂停的任务
   - 停止不需要的任务
   - 删除已完成的任务记录

4. **任务完成**
   - 状态变为：completed
   - 记录总耗时
   - 可以删除记录

## 注意事项

1. **权限控制**
   - 普通用户只能看到自己的任务
   - 管理员可以看到所有任务

2. **资源监控**
   - CPU和内存数据每次更新进度时刷新
   - 使用psutil库获取进程资源占用

3. **任务暂停/继续**
   - 需要在任务执行过程中定期检查状态
   - 暂停时进入等待循环
   - 继续时恢复执行

4. **自动刷新**
   - 前端每5秒自动刷新任务列表
   - 离开页面时停止轮询

5. **错误处理**
   - 任务失败时记录错误信息
   - 状态变为failed
   - 显示错误详情
