# AI助手功能说明

## 功能概述

AI助手是项目管理系统的智能辅助功能，可以帮助团队：
- 基于知识库文档和会议纪要进行智能问答
- 自动生成技术文档、需求文档等
- 提取和总结关键信息
- 识别待办事项并创建任务

## 主要特性

### 1. 智能对话
- 支持多轮对话，理解上下文
- 可引用知识库文档和会议纪要作为背景信息
- 实时显示AI思考状态

### 2. 资源引用
- **知识库文档**：选择相关文档，AI将基于文档内容回答问题
- **会议纪要**：引用会议摘要，提取待办事项和关键决策
- 支持多选，一次性引用多个资源

### 3. 工具支持

#### 生成文档
- 基于选中的资源自动生成完整的技术文档
- 支持Markdown格式
- 自动保存到知识库
- 包含：概述、详细内容、总结等章节

#### 总结内容
- 提取选中资源的核心内容
- 生成关键信息和要点
- 适合快速了解项目状态

#### 提取任务
- 从会议纪要和文档中识别待办事项
- 自动按优先级排序
- 可一键批量创建任务

## 使用方法

### 基本对话

1. 切换到"AI助手"标签页
2. 在左侧面板选择相关的知识库文档或会议纪要
3. 在输入框输入问题
4. 点击"发送"或按 Ctrl+Enter

### 使用工具

1. 选择相关资源（知识库文档或会议纪要）
2. 点击"工具"下拉菜单
3. 选择需要的工具：
   - **生成文档**：创建完整的技术文档
   - **总结内容**：提取核心信息
   - **提取任务**：识别待办事项

### 示例场景

#### 场景1：生成技术文档
```
1. 选择相关的API文档、设计文档
2. 点击"工具" → "生成文档"
3. AI将基于选中资源生成完整的技术文档
4. 文档自动保存到知识库
```

#### 场景2：会议后续跟进
```
1. 选择最近的会议纪要
2. 点击"工具" → "提取任务"
3. AI识别所有待办事项
4. 可批量创建任务到项目中
```

#### 场景3：项目知识问答
```
1. 选择相关的需求文档、技术文档
2. 输入问题："这个功能的实现方案是什么？"
3. AI基于文档内容给出专业回答
```

## 技术实现

### 前端
- Vue 3 + Element Plus
- 双栏布局：资源选择 + 聊天界面
- Markdown渲染支持
- 实时消息滚动

### 后端
- FastAPI + OpenAI API
- 支持工具调用（Function Calling）
- 上下文管理（最近5轮对话）
- 自动保存生成的文档和任务

### AI模型
- 使用系统配置的AI模型（在"AI配置"页面设置）
- 支持OpenAI、通义千问、Gemini等多种模型
- 温度参数：0.7（平衡创造性和准确性）

## 配置要求

### AI配置
1. 进入系统的"AI配置"页面
2. 添加或编辑AI配置：
   - **AI平台**：选择OpenAI、通义千问或Gemini
   - **模型名称**：如 gpt-3.5-turbo、gpt-4o-mini等
   - **API Key**：填入您的API密钥
   - **API地址**：填入API地址（如 https://api.openai.com/v1）
3. 激活配置：点击"激活"按钮
4. 测试连接：确保配置正确

**注意**：AI助手会自动使用当前激活的AI配置，无需额外配置环境变量。

### 依赖包
```bash
pip install openai
```

## 注意事项

1. **AI配置**：确保在"AI配置"页面设置并激活了AI配置
2. **成本控制**：每次对话都会消耗API额度，建议合理使用
3. **内容长度**：知识库文档内容会被截断到2000字符以控制成本
4. **对话历史**：只保留最近5轮对话以控制token消耗
5. **权限**：只能访问当前项目的知识库和会议纪要
6. **模型切换**：可以随时在AI配置页面切换不同的模型

## 常见问题

**Q: AI回复速度慢怎么办？**
A: 这取决于所选AI模型的响应速度和网络状况，通常需要5-15秒。可以在AI配置页面切换到更快的模型。

**Q: 可以使用其他AI模型吗？**
A: 可以，在"AI配置"页面添加不同的AI平台配置（OpenAI、通义千问、Gemini等），然后激活即可。

**Q: 生成的文档保存在哪里？**
A: 自动保存到当前项目的知识库中，分类为"AI生成"，标签为"AI生成"。

**Q: 如何提高AI回答的准确性？**
A: 选择更相关的知识库文档和会议纪要，提供更具体的问题描述。也可以切换到更强大的模型（如GPT-4）。

**Q: 提示"未找到激活的AI配置"怎么办？**
A: 请先进入"AI配置"页面，添加AI配置并点击"激活"按钮。
