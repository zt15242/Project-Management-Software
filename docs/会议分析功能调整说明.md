# 会议分析功能调整说明

## 调整概述

根据新的业务需求，会议分析功能的流程已调整为：

1. **上传视频/音频** → 自动进行转录
2. **转录完成** → 状态变为"转录完成"，显示"查看纪要"按钮
3. **点击"查看纪要"** → 调用AI生成智能纪要
4. **生成完成** → 自动渲染智能纪要页面

## 主要变更

### 后端变更 (backend/routers/meetings.py)

#### 1. 调整转录流程
- **修改位置**: `process_meeting_file` 函数
- **变更内容**: 
  - 转录完成后不再自动调用AI生成摘要
  - 转录文本保存后，状态设置为 `MeetingStatus.WAITING_CONFIRMATION`
  - 等待用户主动点击"查看纪要"按钮

#### 2. 新增API端点
- **端点**: `POST /api/meetings/{meeting_id}/generate-summary`
- **功能**: 首次生成智能纪要（用于转录完成后点击"查看纪要"按钮）
- **流程**:
  1. 验证会议存在性和用户权限
  2. 检查是否有转录文本
  3. 检查AI配置是否启用
  4. 后台任务生成智能纪要
  5. 更新会议状态为 `GENERATING_SUMMARY`
  6. 生成成功后状态变为 `COMPLETED`
  7. 失败则恢复为 `WAITING_CONFIRMATION`

#### 3. 保留现有端点
- **端点**: `POST /api/meetings/{meeting_id}/regenerate-summary`
- **功能**: 重新生成摘要（用于已完成的会议重新生成）

### 前端变更 (frontend/src/views/ProjectDetail.vue)

#### 1. 更新操作按钮逻辑
- **转录完成状态** (`waiting_confirmation`):
  - 显示"查看纪要"按钮（绿色、成功类型）
  - 点击后调用 `handleViewSummary` 函数
  - 按钮带loading状态，防止重复点击

- **已完成状态** (`completed`):
  - 显示"查看摘要"按钮
  - 直接查看已生成的摘要

#### 2. 新增状态变量
```javascript
const generatingSummary = ref(false);
const generatingSummaryId = ref(null);
```

#### 3. 新增处理函数
- **函数名**: `handleViewSummary`
- **功能**:
  1. 检查是否已有摘要，有则直接查看
  2. 否则调用 `/api/meetings/{id}/generate-summary` API
  3. 启动轮询等待生成完成
  4. 自动打开详情对话框显示进度
  5. 生成完成后用户可查看摘要

#### 4. 更新状态文本
- `waiting_confirmation`: "待确认说话人" → "转录完成"

## 用户体验流程

### 旧流程（已废弃）
1. 上传视频 → 转录 → 自动生成摘要 → 完成
2. 问题：用户无法控制何时生成摘要，转录完成后立即消耗AI资源

### 新流程
1. 上传视频 → 转录 → **显示"转录完成"状态**
2. 用户点击"查看纪要"按钮 → **触发AI生成**
3. 生成中显示进度 → 完成后自动展示摘要
4. 优势：
   - 用户可以先查看转录文本
   - 按需生成摘要，节省AI资源
   - 更灵活的控制流程

## 状态流转图

```
上传 (uploading)
  ↓
音频提取 (processing)
  ↓
AI转录 (speaker_identification)
  ↓
转录完成 (waiting_confirmation) ← 【新增：停在这里等待用户操作】
  ↓ 【用户点击"查看纪要"】
生成摘要中 (generating_summary)
  ↓
已完成 (completed)
```

## 测试建议

1. **上传新会议**:
   - 上传一个视频/音频文件
   - 等待转录完成
   - 验证状态显示为"转录完成"
   - 验证显示"查看纪要"按钮

2. **生成智能纪要**:
   - 点击"查看纪要"按钮
   - 验证提示"正在生成智能纪要，请稍候..."
   - 验证状态变为"AI生成摘要中..."
   - 验证自动打开详情对话框
   - 等待生成完成
   - 验证状态变为"已完成"
   - 验证摘要内容正确显示

3. **查看已完成的摘要**:
   - 对于已完成的会议
   - 点击"查看摘要"按钮
   - 验证直接显示摘要内容

4. **错误处理**:
   - 测试AI配置未启用的情况
   - 测试AI调用失败的情况
   - 验证错误提示正确
   - 验证状态恢复为"转录完成"

## 注意事项

1. **兼容性**: 已完成的旧会议仍然可以正常查看摘要
2. **重试机制**: 保留了重新分析和重新生成摘要的功能
3. **轮询机制**: 生成摘要时会启动定时轮询，自动刷新状态
4. **权限控制**: 保持原有的权限验证逻辑
