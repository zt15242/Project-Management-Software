## 🐛 常见问题

### Q1: 模板选择器不显示
**原因**: 组件导入失败或路径错误
**解决**: 检查 `EnhancedTemplateSelector.vue` 文件是否存在

### Q2: 没有模板显示
**原因**: 模板未导入到数据库
**解决**: 运行 `python init_landppt_templates.py`

### Q3: 生成的 PPT 没有使用选中的模板
**原因**: API 参数未正确传递
**解决**: 检查浏览器控制台的网络请求，确认 `template_id` 参数

### Q4: 上传模板按钮不工作
**原因**: `TemplateUploadDialog` 组件有问题
**解决**: 检查组件文件和导入
